# Shadcn UI Setup

This project uses [shadcn/ui](https://ui.shadcn.com/) for UI components.

## Installing Components

To add new shadcn components, use the CLI:

```bash
npm run ui:add
```

Then select the component you want to add from the list.

## Example

```bash
npm run ui:add button
npm run ui:add dialog
npm run ui:add input
```

## Configuration

The shadcn configuration is in `components.json`. Components are installed to `src/ui/components/ui/`.
